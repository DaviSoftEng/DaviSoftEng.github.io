# Portfólio — Davi Machado

Site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro.

🔗 **Acesse:** [davisofteng.github.io](https://davisofteng.github.io)

## Stack

- HTML5 / CSS3 / JavaScript (sem framework)
- WebGL (fundo animado via GLSL shader)
- Devicon + Simple Icons (logos das tecnologias)

## Estrutura

```
portifolio/
├── index.html
├── css/
│   └── style.css
└── js/
    ├── shader.js     # fundo animado WebGL
    ├── carousel.js   # carrossel de projetos
    ├── elastic.js    # linha elástica interativa
    └── main.js       # menu, animações, reveal
```

## Rodando localmente

Basta abrir o `index.html` no navegador — sem build, sem dependências.
